# Upstream sync review, 26 November 2026 (first live run)

The report beside this file is what changed upstream. This is what we did about it.

## Changed upstream

### adloop (7 commits, 17 files)

- **Must follow: Google retired language targeting for Search campaigns.** adloop's rules changed
  for it, and Google confirms it: Ads API change of **30 September 2026**, adding a language criterion
  to a Search campaign now returns an error. **Our Apply connector never sent one**, so nothing was
  broken. Made permanent: the builder agent now says not to add one (write the ad and the page in the
  language you want to reach), and `tests/test_google_operations.py` fails if a new campaign ever
  carries a language criterion (checked by adding one: the test catches it).
- adloop also reworded its budget rule of thumb (5x target CPA is its own rule; Google's guide says 2 to
  3x). Ours is a hard dollar limit in `settings/limits.json`, so **not for us**.
- Its new plain-words approval card: **already covered**; our Apply preview gives a plain summary
  with before and after, and every change needs the Allow click.
- The rest is its own code (Merchant feeds, Reddit, currency). Code is never copied.

### google-ads-skills, free-google-ads-scripts, claude-code (1 commit each)

Mobile-app ad SDK wording, fixes to an anomaly script (GPL-3.0, ideas only), one day of the Claude
Code changelog. **Not for us**; Claude Code is reviewed in full in the main repo's sync.

## New upstream skills reviewed (165, every decision in `upstream/catalog.json`)

**`/tracking-check`** (from Google-Ads-Copilot, claude-ads, marketingskills and Google's own
assistant: five repos had this and we did not). Answers "can we trust the trial numbers?":
auto-tagging, exactly one primary trial conversion counted once per click, no soft actions inflating
results, and trials recorded when there were clicks. Verdict: Trustworthy / Not yet / Broken. It is
now the first line of the weekly review, and the optimizer may not propose a budget raise unless it
says Trustworthy.

**`/landing-check`** (from Google-Ads-Copilot and claude-ads). Rules out a tracking problem first,
then checks the page an ad sends people to: answers fast, says what the ad promised, one clear free
trial step on a phone, same promises as the ad and within the copy rules, the right price. The agents
never edit the website; page problems are reported for a person.
